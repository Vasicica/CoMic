# CoMic

Microfon de telefon pentru Windows. Android + Windows, fara abonament.

Vezi [docs/PLAN.md](docs/PLAN.md) pentru plan si [docs/PROTOCOL.md](docs/PROTOCOL.md) pentru protocol.

- `android/`  aplicatia Android (Kotlin) — Faza 1
- `windows/`  receptorul Windows (Rust) — Faza 1
- `proto-zero/` dovada conceptului cu Python + browser — Faza 0
- `shared/proto/` definitia protocolului
